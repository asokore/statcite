## Pre-release review of the 1.12.2 changes

A second adversarial review ran over the unreleased 1.12.2 commits before they
shipped: four reviewers, each finding checked by an independent verifier that
tried to refute it. It confirmed 21 findings and refuted one. All 21 were fixed
before release, each with a regression test shown to fail on the pre-fix commit.
The ones worth remembering:

- A one-sided year window outside the range was misread as an interior gap.
- "None of the sources publishes it" fired when only one source reported an
  absence and another had been blocked or had data outside the window.
- Outages on registry indicators were coded as the caller's fault.
- The same unknown indicator got different codes on different routes.
- n8n's MCP client, before its 2.3.1 release, injects toolCallId into tool
  arguments, which the new argument check refused. That key is now ignored.
- The integrity job could report a cut connection as a data mismatch, and a
  stalled upstream could run it past its timeout with no result.
