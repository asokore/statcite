Privacy Policy

Effective: July 2026

StatCite is a read-only data service. It is designed to know as little about you as possible.

What we collect

  • No accounts. There is no signup, login, API key, or user database.
  • What we record, precisely. StatCite does not retain free-text queries, claimed values, IP addresses, user agents, headers, or complete request payloads. For aggregate service analytics we record a small set of standardised request categories per call: which tool or endpoint was used, the registry indicator key requested (unrecognised indicators are collapsed to a generic bucket), the resolved ISO3 country code (unresolvable inputs are dropped), the verification verdict kind, success/error outcome, and response time. These fields are drawn from closed sets in code, so arbitrary user text cannot enter the analytics stream. They are emitted as structured log lines within our hosting platform's (Cloudflare) standard short-lived observability retention. We keep no separate long-term store. We do not build profiles or sell any data.
  • No cookies, no trackers, no analytics scripts on this website.

Third parties

Requests are served by Cloudflare (hosting/CDN), whose own privacy policy applies at the network level. Cloudflare's network-level operational logs (which can include IP addresses) are created and retained by Cloudflare under its own policy. This service does not export, store, or analyze them. Data queries are forwarded to official statistical APIs without any information about you attached, so the upstream request contains only the series being requested. The full set of hosts this service contacts: the World Bank (api.worldbank.org), the IMF DataMapper (www.imf.org), the IMF SDMX API (api.imf.org), the BIS (stats.bis.org), the ECB Data Portal (data-api.ecb.europa.eu), Frankfurter (api.frankfurter.app, ECB reference rates) and DBnomics (api.db.nomics.world). FRED is not queried: it is permanently disabled on this deployment (see the documentation §8).
